Build Actions#

Execute Scade One model build actions.

Code generation#

The code-generation action generates code for a Scade One project and a given job.

Source code for this action

Input

Description

Required

Default

scade-dir

Scade One installation directory, e.g. 'C:\Program Files\Ansys Inc\v261\Scade One' or '/opt/AnsysInc/v261/ScadeOne/'.

True

project

Path of the Scade One project.

True

job-name

Name of the job to run. This is used to identify the job in the Scade One actions workflow.

True

target-dir

Path to the generated code, log and mapping files. If not provided, they will be saved in the 'output/code_generation' directory.

False

output/code_generation

artifact-name

Name of the artifact to upload.

False

Generated code and logs

python-version

Python version used for installation and execution of the build process.

False

3.10

use-python-cache

Whether to use the Python cache to install previously downloaded libraries.

False

pip

checkout

Whether to clone the repository on the CI/CD machine.

False

true

Example#

Code generation basic example
code-generation:
  name: "Code generation basic example"
  runs-on: [self-hosted, 'ScadeOne']
  steps:
    - name: "Generate code"
      uses: ansys/scadeone-actions/code-generation@main
      with:
        scade-dir: 'C:\Program Files\Ansys Inc\v261\Scade One'
        project: 'Model\QuadFlightControl\QuadFlightControl.sproj'
        job-name: 'CodeGen'

FMU export#

The fmu-export action builds a FMU package from a given Scade One operator. The FMU export supports the FMI 2.0 version for Model-Exchange and Co-Simulation.

Source code for this action

Input

Description

Required

Default

scade-dir

Scade One installation directory, e.g. 'C:\Program Files\Ansys Inc\v261\Scade One' or '/opt/AnsysInc/v261/ScadeOne/'.

True

project

Path of the Scade One project.

True

job-name

Name of the job to run. This is used to identify the job in the Scade One actions workflow.

True

kind

The FMI kind, ME for Model Exchange, CS for Co-Simulation.

False

ME

target-dir

Path to the output directory where the files are generated. If not provided, they will be saved in the 'output/fmu_gen' directory.

False

output/fmu_gen

artifact-name

Name for the uploaded artifact. This will be used as the name for the FMU archive.

False

fmu-file

python-version

Python version used for installation and execution of the build process.

False

3.10

use-python-cache

Whether to use the Python cache to install previously downloaded libraries.

False

pip

checkout

Whether to clone the repository on the CI/CD machine.

False

true

Limitations

Imported Type

The FMU export is not possible if imported types are used for any of the inputs or outputs of the selected operator, or sensors in the scope of the export.

Supported Platforms

This version only supports gcc compiler on 64-bits Windows platform.

Example#

FMU build basic example
fmu-export:
  name: "FMU build basic example"
  runs-on: [self-hosted, 'ScadeOne']
  steps:
    - name: "FMU export"
      uses: ansys/scadeone-actions/fmu-export@main
      with:
        scade-dir: 'C:\Program Files\Ansys Inc\v261\Scade One'
        project: 'Model\QuadFlightControl\QuadFlightControl.sproj'
        job-name: 'CodeGen'
